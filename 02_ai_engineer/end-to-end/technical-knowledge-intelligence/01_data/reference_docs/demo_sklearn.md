# Random Forest and PCA

Random Forest is an ensemble of decision trees. Each tree is trained with randomness in observations and/or candidate features, which reduces correlation between trees. Classification aggregates tree votes or probabilities. Useful evaluation includes cross-validation and per-class metrics.

PCA projects centered data onto orthogonal directions of maximum variance. The directions are eigenvectors of the covariance matrix or can be computed through singular value decomposition. Standardization is often important when feature scales differ.
