# Documentation / Dokumentáció

This directory is intentionally split by language so the technical material is not mixed across Hungarian and English.

A dokumentáció nyelvenként külön struktúrában található, hogy a magyar és angol anyagok ne keveredjenek.

- [Magyar dokumentáció](hu/00_DOKUMENTACIOS_TERKEP.md)
- [English documentation](en/00_DOCUMENTATION_INDEX.md)
- [Shared diagrams](shared/visuals/)

Both language trees follow the same conceptual order: project overview → architecture → data → tool calling → routing/orchestration → model training → evaluation/statistics → UI/usage → code/repository audit → limitations/next steps → preset scenarios → visualization system.
